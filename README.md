# ⚔️ FFXIV 副本开荒犯错记录表

一个面向 FFXIV 静态队的在线犯错记录与复盘工具。队长记录犯错，队员添加复盘备注，一键生成群公告总结。支持 FFLogs 数据导入、技能时间轴、数据可视化图表。

**[📍 在线使用](https://shiraishiyokai.github.io/ffxiv-raid-tracker/ffxiv-raid-tracker.html)**

## 🚀 使用方法

### 队长（首次使用）

1. 打开页面，网址末尾加 `#captain` 进入队长模式：
   ```
   https://shiraishiyokai.github.io/ffxiv-raid-tracker/ffxiv-raid-tracker.html#captain
   ```
2. 页面自动创建新队伍，URL 会变为 `?team=xxx#captain`
3. **收藏这个 URL**，以后直接打开就是你的队伍
4. 点击 **📋 复制分享链接** → 把队员链接发到群里

### 队长（日常使用）

1. 打开之前收藏的队长链接
2. 选择日期（默认今天，凌晨 4 点前自动归为前一天）
3. 在快速记录栏录入犯错：
   - **方式一**：点击队员按钮 `[MT]` → 输入描述 → `Enter`
   - **方式二**：点击预设按钮 `[+踩圈]` → 自动添加到选中队员
   - **方式三**：键盘 `1`-`8` 选队员 → 输入描述 → `Enter`
4. 点击 **☁️ 保存到云端** 确保数据同步
5. 开荒结束后点击 **📋 生成当日总结** → 复制到群公告

### 队员

1. 打开队长发的队员链接（不带 `#captain`）
2. 点击犯错条目的 ▶ → 填写复盘备注
3. 点击 **☁️ 保存到云端** 确保备注同步

### 导入 FFLogs 数据

1. 点击 **🧙 导入 FFLogs** 按钮
2. 输入 FFLogs 报告链接（如 `https://cn.fflogs.com/reports/abc123`）
3. 系统自动获取战斗列表、死亡事件、减伤技能释放数据
4. 如有未自动匹配的玩家，手动选择对应位置即可
5. 导入完成后数据自动保存到云端

### 新建队伍

- 队长点击连接栏的 **🆕 新建队伍** 按钮
- 旧队伍数据保留在云端，可通过旧链接随时切换回来

| 链接 | 格式 | 权限 |
|------|------|------|

## 📊 数据可视化

### 总览趋势折线图

点击 **📈 总览趋势** 按钮（toggle 切换，展开时按钮变金色），显示折线图：

| 指标 | 说明 |
|------|------|
| 最远进度 | 每日最远进度趋势，Y轴显示P标签，tooltip显示"P3 50%"等含boss血量的格式 |
| 累计时长 | 累计开荒时间，Y轴单位为小时 |
| 犯错次数 | 每人犯错次数趋势，可选全部成员(8条线)或单个成员 |

### 团灭分布柱状图

点击 **📊 团灭分布** 按钮，显示柱状图+日历选择器：

- 日历中绿色高亮的日期有 FFLogs 战斗数据，点击即可查看
- 柱状图按P阶段（P1/P2/P3等）统计团灭次数
- 切换主页面日期时图表自动更新

| 操作 | 说明 |
|------|------|
| 队长保存 | 点击「☁️ 保存到云端」→ 本地 + 云端双重保存 |

## ❓ 常见问题

### Q: 队员看不到最新数据？
确保队长已点击「☁️ 保存到云端」。队员页面会自动刷新，也可手动刷新浏览器。

### Q: 如何切换队伍？
队长点击「🆕 新建队伍」创建新队伍。旧队伍通过收藏的链接随时切换。

### Q: 数据会丢失吗？
数据同时保存在本地 localStorage 和云端 GitHub。刷新页面会自动拉取云端最新数据。

### Q: FFLogs 导入后看不到技能时间轴？
确保报告包含减伤技能释放记录。只有 `MITIGATION_ABILITIES` 中定义的 76 个技能才会显示在时间轴上。

### Q: 代码推送后页面没更新？
GitHub Pages 有约10分钟 CDN 缓存，硬刷新（`Cmd+Shift+R`）通常可解决。
